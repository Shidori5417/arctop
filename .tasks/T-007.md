pub enum Control { SetInterval(Duration), Stop }
pub struct Sampler { /* JoinHandle, kontrol Sender'ı */ }
impl Sampler {
    /// Thread'i başlatır; her turda önce Snapshot::empty(now), sonra tüm kaynakların sample'ı.
    /// İlk turdan önce her kaynağın probe'u bir kez çağrılır; sonuçlar `capabilities()` ile alınır.
    pub fn spawn(fs: SysFs, dev: Device, sources: Vec<Box<dyn MetricSource>>, interval: Duration) -> (Sampler, crossbeam_channel::Receiver<Snapshot>);
    pub fn set_interval(&self, d: Duration);

    pub fn stop(self);                                // thread'i durdurup join eder
}
/// Ayrı thread olmadan tek seferlik iki örnek (Δ metrikler için) — `--once` için.
pub fn sample_once(fs: &SysFs, dev: &Device, sources: &mut [Box<dyn MetricSource>], gap: Duration) -> Snapshot;

// history.rs

impl History { pub const CAPACITY: usize = 300; pub fn new() -> Self; pub fn push(&mut self, s: &Snapshot); /* + her seri için erişimci */ }

## Davranış
- tokio yok (ADR-001). Tek `std::thread`. Snapshot kanalı `crossbeam_channel::bounded(2)`; kanal doluysa **en eski** snapshot atılır (örnekleyici, kendinde tuttuğu Receiver klonuyla bir tane çekip yeniden gönderir). UI tarafı Receiver düşürülürse thread temiz kapanır.
- Bekleme `crossbeam_channel::select!` + `recv_timeout`/`after` ile kontrol kanalında yapılır, böylece `Stop` ve `SetInterval` anında etki eder. Aralık sapması birikmesin (bir sonraki tetik = önceki tetik + interval; geride kalınırsa hemen örnekle).
- `History::push`: `Metric::Value` → `Some(v as f64)`, `Unavailable` → `None` (grafikte boşluk). `busy_total` = `s.engines` içindeki en yüksek `busy_pct` (boşsa `None`).
- `unwrap`/`expect` yalnızca testlerde.
