## Sabit arayüz
```rust
// cli.rs
#[derive(clap::Parser, Debug)]
#[command(name = "arctop", version, about = "Intel Arc GPU'lar için terminal tabanlı izleme aracı")]
pub struct Cli {
    /// Örnekleme aralığı (ms), 250..=5000
    #[arg(long, default_value_t = 1000, value_parser = clap::value_parser!(u64).range(250..=5000))]
    pub interval: u64,
    /// DRM kart numarası (/sys/class/drm/cardN). Verilmezse ilk Intel GPU.
    #[arg(long)]
    pub card: Option<u32>,
    /// Tek ölçüm alıp çık (Δ metrikler için iki örnek arasında --interval kadar bekler)
    #[arg(long)]
    pub once: bool,
    /// --once çıktısını JSON yaz
    #[arg(long, requires = "once")]
    pub json: bool,
}
// output.rs
pub fn to_json(dev: &Device, s: &Snapshot) -> serde_json::Value;
pub fn to_text(dev: &Device, s: &Snapshot) -> String;
```

## Davranış
- `main`: `Cli::parse()`. `--card N`: `discover` sonucundan `card == N` olan; yoksa `anyhow` hatası, bulunan kartları listeler. `--once` değilse `run_tui(fs, dev, Duration::from_millis(interval))`.
- `--once`: kaynakları oluştur, **her birinin `probe`'unu çağır** (ADR-009), sonra `sample_once(.., gap = interval)`; `--json` ise `to_json` → `serde_json::to_string_pretty` stdout'a; değilse `to_text`. TUI/terminal raw mode açılmaz.
- JSON biçimi (düz ve script dostu; derive edilmiş `Metric` biçimini kullanma):
  ```json
  { "card": 1, "name": "Intel Arc A750", "driver": "i915", "pci_slot": "0000:03:00.0",
    "freq_mhz": {"act": 600, "cur": 600, "min": 300, "max": 2400, "boost": 2400},
    "power_w": 35.2, "power_limit_w": 190.0, "temp_c": 48.0, "fan_rpm": 720, "voltage_mv": 755,
    "vram_used_bytes": 1157603328, "vram_total_bytes": null,
    "engines": {"render": 12.5, "copy": 0.0},
    "procs": [{"pid": 1815, "comm": "Hyprland", "vram_bytes": 26214400, "engines": {"render": 3.1}}],
    "unavailable": {"vram_total_bytes": "sysfs'de yok"} }
  ```
  Unavailable alanlar `null` olur ve nedeni `unavailable` haritasında yer alır. Motor anahtarları `EngineClass::as_fdinfo_key()`.
- `to_text`: birkaç satırlık insan okunur özet (`fmt::metric` kullan).
