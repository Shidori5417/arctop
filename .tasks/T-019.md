# T-019: Release iş akışı ve AUR PKGBUILD

- **Dal:** main (Claude alt ajanı, ana ağaç)

## Amaç
`v*` etiketinde Linux binary'si üretip GitHub Release'e eklemek; AUR için PKGBUILD hazırlamak. Mevcut CI (`ci.yml`) zaten fmt/clippy/test yapıyor.

## Okunacaklar
- .github/workflows/ci.yml
- Cargo.toml (kök), crates/arctop/Cargo.toml

## Sahip olunan dosyalar
- .github/workflows/release.yml (yeni)
- packaging/aur/PKGBUILD (yeni), packaging/aur/.SRCINFO (yeni)
- crates/arctop/Cargo.toml (yalnızca `description`, `repository`, `readme`, `keywords`, `categories` paket alanları)
- Cargo.toml (kök; yalnızca `[profile.release]`: `lto = "thin"`, `codegen-units = 1`, `strip = true`)

## Ayrıntılar
- release.yml: `on: push: tags: ['v*']`; ubuntu-latest; `dtolnay/rust-toolchain@stable`; `cargo build --release --locked -p arctop`; `arctop-${tag}-x86_64-linux.tar.gz` (binary + README + LICENSE-*) ve `.sha256`; `softprops/action-gh-release@v2` ile yükle; `permissions: contents: write`.
- PKGBUILD: `pkgname=arctop`, `pkgver=0.1.0`, `arch=('x86_64')`, `license=('MIT' 'Apache-2.0')`, `depends=('gcc-libs')`, `makedepends=('cargo')`, kaynak GitHub tag arşivi (`v$pkgver`), `sha256sums=('SKIP')` ve yanında "ilk release sonrası güncellenecek" yorumu; Arch Rust paketleme kurallarına uygun `prepare()` (`cargo fetch --locked --target "$(rustc -vV | sed -n 's/host: //p')"`), `build()` (`cargo build --frozen --release -p arctop`), `check()` (`cargo test --frozen`), `package()` (binary, iki lisans, README).
- `.SRCINFO`: `makepkg --printsrcinfo` varsa onunla üret, yoksa elle eşdeğerini yaz.
- `namcap` varsa PKGBUILD'i kontrol et.
- Workspace sürümü 0.1.0 değilse raporda belirt (değiştirme).
